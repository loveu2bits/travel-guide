# 2026 十一四选一 · 旅游攻略网站设计

> 日期：2026-07-24  
> 状态：待用户确认后进入实现计划

## 1. 目标

为「淄博出发 · 两人 · 10.2–10.6」的四条候选线路做一套**手机优先、浅色、好看**的静态网站：首页做横向对比与决策，四个详情页完整呈现现有 Markdown 攻略，并配上美食/景点代表性图片。

成功标准：

- 手机上可舒适浏览（单手滑动、表格不崩、字号可读）
- 首页 30 秒内能看懂「哪个更适合我」
- 详情页信息完整度对齐现有 `攻略.md`（不删实质内容）
- 视觉有目的地个性，但不花哨到干扰阅读

## 2. 范围

**做：**

- 纯静态多页：`index.html` + 四个目的地页
- 共享 `css/`、`js/`、本地或稳定外链图片
- 首页：结论、打分表、适合谁、行动日历、四个入口
- 详情页：亮点 / 交通 / 行程表 / 每日安排 / 住宿 / 美食 / 十一提示 / 弹性备选
- 响应式布局、轻动效、`prefers-reduced-motion`

**不做：**

- 构建工具 / React / CMS
- 在线订票、地图 SDK、用户登录
- 后端与数据库
- 强行改写攻略事实（票价、车次等以现有 md 为准，页脚注明「以官方为准」）

## 3. 信息架构

```
index.html                 # 决策首页
shanxi.html                # 山西
wuhan-changsha.html        # 武汉-长沙

assets/
  css/main.css
  js/main.js
  images/                  # 各目的地 hero / 景点 / 美食图
```

导航：

- 全站顶栏：Logo/标题「十一四选一」+ 四个目的地短链 +（详情页）「返回对比」
- 详情页次级锚点：亮点 · 交通 · 行程 · 美食 · 住宿 · 提示（手机可横向滚动）

## 4. 页面设计

### 4.1 首页 `index.html`

1. **Hero**：浅色全宽氛围图或柔和渐变平面 + 品牌级标题「2026 十一 · 四选一」+ 一行副文（淄博出发 / 5 天 4 晚 / 两人）+ 主 CTA「看对比」滚到打分区。第一屏不堆统计条、不叠浮层贴纸。
2. **一句话结论**：突出 `山西 ≥ 武汉-长沙 > 福州-泉州 > 成都-重庆` 及一句解释。
3. **打分表**：桌面表格；手机改为每个目的地一张竖向分数卡，或表格横向滑动 + sticky 第一列。美食维度标注「权重 ×2」。
4. **适合谁**：四个短段，可点进对应详情。
5. **四个入口卡**：大图 + 地名 + 一句卖点 + 预算/交通标签 → 进详情。
6. **行动日历**：现在 / 9.18 / 9.22 / 9.26–28 / 出发前 3 天。

### 4.2 详情页（四页同构）

1. **Hero**：该目的地代表景全宽大图 + 地名 + 一行亮点。
2. **亮点速览**：美食 / 古迹 / 自然 三块，配图。
3. **大交通**：保留方案对比与票价区间。
4. **行程速览**：桌面表；手机按日卡片（上午/下午/晚上）。
5. **每日详细安排**：按 D1–D5 分节，可折叠（默认展开 D1，或全部展开由实现时定：完整攻略场景默认全部展开，仅长日提供「收起」）。
6. **住宿建议**、**美食清单**（网格图文）、**十一特别提示**、**弹性备选**。
7. **页脚**：返回对比 + 相邻目的地快捷链 + 免责声明。

## 5. 视觉方向

| Token | 用途 | 值（实现时可微调） |
|---|---|---|
| `--bg` | 页面底 | `#F7F5F2` 雾白 |
| `--surface` | 内容面 | `#FFFFFF` |
| `--ink` | 主文字 | `#1C1917` |
| `--muted` | 次要文字 | `#78716C` |
| `--line` | 分割线 | `#E7E5E4` |
| 山西 accent | 古建赭 | `#B45309` |
| 两湖 accent | 江岳青 | `#0F766E` |
| 闽南 accent | 海绿 | `#0369A1` |
| 成渝 accent | 辣红 | `#C2410C` |

字体（Google Fonts 或国内可访问镜像）：

- Display：`Fraunces` 或 `Source Han Serif SC`（标题，克制使用）
- Body：`DM Sans` + 系统中文回退 `PingFang SC`, `Noto Sans SC`

签名元素：**「目的地色条 + 大衬线地名」** 出现在每页 Hero 与入口卡，一眼认出线路，其余界面保持安静。

避免：紫色渐变模板感、奶油底+陶土衬线默认套、报纸密栏、暗黑模式、圆角胶囊标签堆、多层阴影、emoji 装饰。

动效：页面载入淡入；滚动时区块轻微上浮；入口卡 hover 微移；尊重 `prefers-reduced-motion: reduce`。

## 6. 图片策略

- 每个目的地：1 张 Hero + 3–6 张景点 + 3–6 张美食（可复用公开图床 / Unsplash / 维基等允许商用或个人项目使用的图源）。
- 下载到 `assets/images/<city>/`，文件名语义化（如 `pingyao-wall.jpg`），避免热链失效。
- 每图 `alt` 写清内容；Hero 用 `loading="eager"`，其余 `lazy`。
- 找不到理想图时用高质量近似场景，不放无关占位图。

## 7. 技术约束

- 无构建步骤：浏览器直接打开或任意静态托管。
- 语义 HTML5：`header` / `main` / `section` / `nav` / `table`（辅以卡片替代方案）。
- CSS：自定义属性 + 移动优先 media queries；断点约 640 / 960。
- JS：仅锚点高亮、可选折叠、移动表格增强；无框架。
- 可访问性：可见 focus、足够对比度、图片 alt。

## 9. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 手机上宽表难读 | 行程改为按日卡片；打分表横滑或分卡 |
| 外链图失效 | 下载到本地 `assets/images` |
| 中文字体加载慢 | `font-display: swap` + 系统中文回退 |
| 内容过长 | 详情页锚点导航；章节清晰间距 |
